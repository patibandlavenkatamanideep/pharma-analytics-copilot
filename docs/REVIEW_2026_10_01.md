Found while mapping, beyond the review's text:

- **R5 is worse than an acceptance gap.** `sales.pack_units` and `sales.wac`
  are `DOUBLE PRECISION`, which stores `NaN` and `Infinity`. A NaN WAC that
  passes validation would be **published** into the facts the analytics read.
  To be reproduced on PostgreSQL.
- **R2 has a second bypass.** Rate windows count rows of `app_conv.runs`,
  which are deleted with their conversation (`ON DELETE CASCADE`). Deleting
  conversations would reset a user's rate count.
- **Rejection reasons are free text** and the apply-failure path stores raw
  exception text (`failed during apply: {exc}`) in `app_ingest.batches`.
- **`scripts/bootstrap_db.py --drop`** takes the database name only from the
  process environment and defaults to `pharma_analytics`. The release-gate
  provisioning in this round runs through a wrapper that refuses that name.

  security count from 366 to 370, so `tests/unit/test_documented_counts.py`

  DELETE` on `run_attempts`. `test_fresh_provisioning` showed that 004's
  blanket grant adds `UPDATE` on a second migration pass. 021 now revokes
